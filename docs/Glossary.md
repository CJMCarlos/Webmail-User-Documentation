| **Term**                          | **Definition**                                                                                                                                                                                                               |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **BCIT Email**                    | Your official email address provided by the British Columbia Institute of Technology (BCIT), typically in the format of @student.bcit.ca or @bcit.ca, used for account verification and student benefits.                    |
| **Cloud Credits**                 | Free credits or funds provided by cloud service providers (such as AWS, Azure, or DigitalOcean) as part of the GitHub Student Developer Pack to help students build and deploy applications.                                 |
| **Email Signature**               | A customizable block of text automatically added to the end of your emails, typically containing your name, contact information, and professional details. Used to provide a professional appearance to your correspondence. |
| **Identity** | An identity is a kind of profile that contains your name, email address, organization and signature, while also allowing you to set automatic fowarding to different emails.|
| **External Email Client / Native Client**         | A desktop or mobile application (such as Microsoft Outlook, Apple Mail, or Mozilla Thunderbird) that allows you to manage and send emails from your BCIT account without using the web-based MyBCIT interface.               |
| **IMAP** | Internet Message Access Protocol (IMAP) is a protocol that synchronizes emails by storing messages on a central server instead of storing them locally. |
| **SMTP** | Simple Mail Transfer Protocol (SMTP) is the standard protocol for sending emails across IP networks. |
| **STARTTLS** | STARTTLS is a security protocol that encrypts plaintext email connections into a secure connection. |
| **Filter Rule**                   | A specific condition or set of conditions defined within a filter that determines which emails will be automatically processed. For example, filtering emails based on sender, subject line, or keywords.                    |
| **Filter Set**                    | A collection of rules (filters) that automatically process your incoming messages based on criteria you define.                                                                                                              |
| **GitHub Billing Information**    | Your payment and account details on GitHub, including your full legal name and billing address. This must match your academic affiliation documents for successful student status verification.                              |
| **GitHub Classroom**              | A platform integrated with GitHub that allows educators to create assignments and manage student work, enabling educators and students to develop together.                                                                  |
| **GitHub Pro**                    | A premium GitHub subscription that includes unlimited public and private repositories, advanced features, and collaboration tools at no cost for verified students.                                                          |
| **GitHub Student Developer Pack** | A collection of free tools and services provided by GitHub for students, including GitHub Pro, cloud credits, design software, and more. Available to verify students at educational institutions worldwide.                 |
| **GitHub User Profile**           | Your personal GitHub account page that displays your profile information, including your full name, bio, avatar, and activity history. A complete profile with accurate information is required for student verification.    |
| **MyBCIT**                        | BCIT's web-based student portal that provides access to email, course information, academic records, and other student services. The email component uses the Roundcube webmail system.                                      |
| **Student Status Verification**   | The process of confirming your enrollment at an educational institution through GitHub Education, typically using your school email address or student ID documentation.                                                     |
| **Two-Factor Authentication**     | A security feature that requires two forms of verification (such as a password and a code from your phone) to access your GitHub account, protecting it from unauthorized access.                                            |
| **Verified Student**              | A status on GitHub indicating that your student status has been confirmed through your school email address or other official documentation, allowing you to access student benefits and packages.                           |
